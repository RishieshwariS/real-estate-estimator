# 🏡 Real Estate Price Prediction System

Built a full-stack AI-powered real estate prediction system using microservice architecture.

## 🚀 Tech Stack
- React.js
- Node.js + Express.js
- MongoDB
- Python + Flask
- Scikit-learn

## ⚙️ Features
- Real-time price prediction
- Input: area, bedrooms
- Stores prediction history
- Full-stack + ML integration

## 🧠 Architecture
React → Node → Flask → ML → MongoDB
